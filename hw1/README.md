# ДЗ 1 по RecSys: рекомендации фильмов на MTS KION

**Выполнил:** Собол Жан М05-613а

**Датасет:** [MTS KION](https://github.com/irsafilo/KION_DATASET) — открытые логи онлайн-кинотеатра МТС KION за март–август 2021
([статья](https://arxiv.org/abs/2209.00325), [описание полей](https://ods.ai/competitions/competition-recsys-21/data)).

## Что я сделал

- Для работы выбрал только фильмы, так как для сериалов процент досмотра не всегда отражает интерес пользователя.
- Считал, что фильм понравился, если пользователь посмотрел хотя бы 50%.
- Разделил данные по времени на train, validation и test.
- Отобрал активных пользователей и популярные фильмы. В итоге получил **470 тыс. взаимодействий, 30 тыс. пользователей и 6 880 фильмов**.
- Реализовал пять моделей рекомендаций, подобрал для них лучшие параметры и сравнил качество на тестовых данных по **NDCG@10, Recall@10 и покрытию каталога**.

## Результаты на test

| Модель | NDCG@10 | Recall@10 |
|---|---|---|
| ItemKNN | **0.1124** | 0.1494 |
| EASE | 0.1097 | **0.1495** |
| iALS + свой таргет | 0.1038 | 0.1462 |
| iALS | 0.1013 | 0.1420 |
| FM (ID + метапризнаки) | 0.0904 | 0.1178 |
| Популярное (baseline) | 0.0849 | 0.1076 |

Лучше всего сработали ItemKNN и EASE. Мой таргет для iALS (учёт процента досмотра) дал +2.5% NDCG@10 к обычному iALS
при тех же остальных параметрах. Подробности и выводы — в конце ноутбука.
